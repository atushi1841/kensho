# 懸賞7件の自動応募ログを全部集計したら、「応募導線」と「当選枠」に地味な崖があった

国内懸賞 **7件**を自動収集し、3アカウントで **3件**のエントリーを実行した。その生ログから、応募導線・当選枠・締切の分布を機械可読な形で集計したのがこのレポートだ。手作業では絶対に作れない「7件横断の傾向」を見ていく。

## 何を測ったのか

- 対象: `data/collected_today.json` ほかスナップショット（7件）

- 実行: 自動応募 3件（アカウントあたり案件カバー率 14.3%）

- 判明した当選枠合計 16口 / 推定賞品価値 1,000円


## わかったこと(1): 伸びているキーワード

最も多く出現したのは **（W40キーワード未定義）**。W39同款は `#プレゼント企画`（15件）、`BOOTH`（7件）、`#その場で当たる`（6件）。単なる出現数ではなく、「そのキーワードの案件にどれだけ自動応募が刺さったか（応募率リフト）」も併記している。リフトが正のキーワードは、運用側の判断と需要が噛み合っている語だ。


## わかったこと(2): 当選枠の構造

枠数構成比は **2〜5名 3件**、**1名（最難関） 3件**、**枠数不明・記載なし 1件** の順。枠が大きい案件ほど当選確率は上がり、実際に当選が積み上がっている枠レンジは実測当選テーブルを見ればわかる。


## わかったこと(3): 参加導線という見えない壁

応募導線は X 100.0%。X内で完結する案件は自動化できるが、LINE・外部フォーム・会員IDは1件ごとに人手または専用実装が必要で、ここが実質的な参入障壁になる。

## 再現方法

```bash
python3 scripts/kensho_data_journalism.py --week 2026W40
```

統計JSONは `reports/journalism/2026W40.json` に出力される。同じ入力からは同じ数値が出る（乱数も時刻依存の集計もを使っていない）。

## まとめ

自動化の勝率を上げるのに効くのは、根性ではなく「構造の可視化」だった。
どの導線が自動化できて、どの枠レンジに当選が積み上がり、どのキーワードの案件に応募が回っていないか——
それらを毎週機械的に出し続けておくと、改善の順番が迷わなくなる。
