# 調査レポート 2026-10-09 / Kensho資産活用収益化

## テーマ

## 発見した情報

### 1. Apify StoreでのActor有料公開（80%開発者還元）
- **情報源**: [Apify公式ドキュメント](https://docs.apify.com/actors/publishing/monetize)
- **信頼度**: 高
- **概要**: Apify Storeでは有料Actorのパブリッシュが可能。PPE(Pay Per Event)または従量課金。開発者還元率80%、 payout最低$10〜$20。Agentic payments対応でAIエージェント経由の自動購入も可能。2026年10月にcompute-time料金制度が廃止予定でPPE重視にシフト。
- **実例**: Olivier Reynaud氏が6ヶ月で98 Actorを公開し2,500ユーザー・月数千ドル収益達成[出典: Apify Blog 2026-07-22](https://blog.apify.com/building-98-actors-on-apify-store/)

### 2. データAPI Monetizationモデル
- **情報源**: [Moesif Blog "Monetizing Proprietary Data Through APIs"](https://www.moesif.com/blog/monitoring/Monetizing-Proprietary-Data-Through-APIs/) (2025-03)
- **信頼度**: 高
- **概要**: Data as a Service(DaaS)市場は2033年までに急成長。主要収益モデルは(1) Pay-per-Use (APIコール課金)(2) Subscription (月額固定)(3) Prepaid PAYG (先払いクレジット) (4) Freemium。Bloomberg IntelligenceはAI市場が2032年に$1.3Tに到達と予測。AI企業は独自データセットを必要としている。

### 3. RapidAPI市場での個人開発者収益実態
- **情報源**: [Reddit r/devsarg スレッド](https://www.reddit.com/r/devsarg/comments/1lkp8k2/mi_experiencia_con_rapidapi_de_0_a_4_clientes/) / [Latenode Community](https://community.latenode.com/t/individual-developers-earning-revenue-through-rapidapi-marketplace/36813)
- **信頼度**: 中（個人エピソード）
- **概要**: RapidAPIでは「 Even in a marketplace, you have to "go sell."」—市場 alone では売れない。コンバートには自己プロモーション必須。データパーシングAPIで月$数百〜$数千規模の実例あり。

### 4. ウェブスクレイピング市場動向2026
- **情報源**: [Browserless "State of Web Scraping 2026"](https://www.browserless.io/blog/state-of-web-scraping-2026) (2026-01)
- **信頼度**: 高
- **概要**: AI駆動抽出・実ブラウザ要件・コンプライアンス強化が3大トレンド。ボット検出強化によりDIYスクレイピング維持コスト増加。Managed infrastructure移行が主流。

## Kenshoへの適用提案

### Candidate 1: Apify Store有料Actor展開
- **モデル**: PPE/従量課金Actor公開
- **価格帯**: $0.01〜$0.10/event または月額サブスクリプション
- **Kensho資産**: 58本のApify Actor + スクレイピングノウハウ
- **期待効果**: 月$100〜$500（長期的に増加）
- **実装コスト**: 低（既に58本有）。有料化設定のみ
- **リスク**: 競合多数、プロモーション必要
- **優先度**: **高**（即実行可能・既存資産活用）

### Candidate 2: 懸賞・景品データDaaS API
- **モデル**: 定期更新的スクレイピングデータをAPI経由で販売
- **対象**: 市場調査企業、競合分析チーム、投資家
- **価格帯**: 月額$50〜$500（tiered）
- **Kensho資産**: kenshou.club/cp.meikan.org等データ収集パイプライン
- **期待効果**: 月$500〜$2,000（顧客5-10名で達成）
- **実装コスト**: 中（API層構築に1-2週）
- **リスク**: 法的グレーゾーン、データ利用規約
- **優先度**: **中**（法的検討必要）

### Candidate 3: 日本市場特化スクレイピングSaaS
- **モデル**: EC価格監視・在庫監視・レビュー収集
- **対象**: 小売業者、EC事業者
- **価格帯**: 月額¥5,000〜¥50,000
- **Kensho資産**: プロキシ分離技術・複数垢自動化・レート制限回避ノウハウ
- **期待効果**: 月¥50,000〜¥200,000
- **実装コスト**: 高（SaaS基盤・決済・CS）
- **リスク**: 競合多（Bright Data等）、継続維持コスト
- **優先度**: **低**（Kensho主目的と重複、投資対効果疑問）
