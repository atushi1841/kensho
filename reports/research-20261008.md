# 収益化アイデア調査レポート (2026-10-08)

## 候補1: Niche Data API on RapidAPI
- **モデル**: 既存データパイプラインをRapidAPIに出品、サブスク収益
- **ターゲット**: 開発者・データサイエンティスト
- **収益モデル**: Freemium (Free/PRO $25/ULTRA $75/MEGA $150/mo)
- **根拠**: RapidAPIは40,000+API・4M+開発者規模 (1xapi.com)。年間API管理市場は$8B・成長率25%+ (ZTABS)。ニッチデータAPIは50~100契約で月$2,000~$8,000 (1xapi)
- **Kensho適合**: 既存収集パイプラインをそのままAPI化。迅速出荷可能
- **コスト/リスク**: 低〜中 (APIラッピングのみ)。TOSグリーン領域要確認
- **優先度**: 高

## 候補2: Apify Store 有料Actor出品
- **モデル**: Apify Storeに有料Actorを出品、PPE課金
- **ターゲット**: Apifyユーザー・AIエージェント
- **収益モデル**: Pay-per-event (Apifyが20%手数料、開発者80%)
- **根拠**: Apify Store 83,000+ツール。PPEが2026年 flagship モデル (use-apify.com)。Rentalは2026/10/1完全廃止
- **Kensho適合**: 既存58本のApifyワークフローを有料化。Kensho専用Actor (懸賞応募等) も検討可
- **コスト/リスク**: 低 (出品のみ)。審査/ドキュメント作成労力
- **優先度**: 高

## 候補3: B2B 代替データサービス (リードリスト/価格監視)
- **モデル**: Scraping→構造化データ→B2Bへの有料リード提供 or ダッシュボード
- **ターゲット**: 中小B2B企業・アナリスト
- **収益モデル**: 月額サブスク or 一括ライセンス
- **根拠**: Web Scraping市場は2026年$1.56B→2031年$3.49B、CAGR 17.39% (Mordor Intelligence)。代替データ金融分野は67%の専門家が導入 (Forage AI)。Asia-Pacificが最速成長
- **Kensho適合**: 情報収集パイプラインを活かせる。競合監視ダッシュボード化が近い
- **コスト/リスク**: 中 (営業が必要)。法的/TOSリスク高め
- **優先度**: 中

## 次のテーマへの申し送り
- 各候補のTOS適合性を詳細検証 (Apify PPE条件、X/TW scraping TOS)
- 価格設定のベンチマーク調査 (類似Actor/APIの価格帯)
- Kensho既存ワークフローの有料化可能件数の棚卸し
