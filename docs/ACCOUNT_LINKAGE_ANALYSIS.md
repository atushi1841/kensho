## 8. 緊急時チェックリスト（凍結発生時）

1. **即時**: 該当垢を config.yaml でコメントアウト（応募停止）
2. **即時**: セッションファイルを `data/frozen/` に退避
3. **確認**: `curl -s "https://api.fxtwitter.com/{handle}"` で凍結確定
4. **分析**: 直前7日間の audit.jsonl から機械的パターン抽出
5. **判断**: atushi16なら異議申し立て最優先 / 他垢なら新垢作成で再構築
6. **報告**: 改善アンカー（improvement-anchor.md）に記録

---

**結論**: 現状の技術的防御（11項目）は十分。残る最大リスクは **「同一WSLゲートウェイIP（172.26.80.1）経由でのクラスターリンク」** のみ。この解決（別WSL/別マシンSOCKS5ゲートウェイ）が連座リスク完全排除の鍵。
