## 2. Scrapling 0.4.11〜0.4.15 の変更点（信頼度: 高）

出典: `https://raw.githubusercontent.com/D4Vinci/Scrapling/main/CHANGELOG.md`、`https://github.com/D4Vinci/Scrapling/releases`（GitHub一次情報）

- **0.4.13**: Playwright/Patchright のバージョンピンを**外した**（自前の UA が実ドライバの Chromium 版に追従）/ `browserforge` の指紋データがブラウザ版に遅れると **import 時に ValueError で落ちる** バグを修正 / `scrapling install --force` が必要になった。
- **0.4.14**: 0.4.13 が **uv で無言フォールバック（古い版が入る）** 問題を修正。Kensho は uv.lock を持つため、0.4.13 は選ばないこと。
- **0.4.15**: Cloudflare Turnstile の解法がロケール非依存になり、**headless の無限ループを修正**（#411/#422）。ブラウザタブが保持・再利用される（リクエスト毎の再起動が不要）。`Response.markdown()`（RAG向け）と `SiteToMarkdownSpider` 追加。`Fetcher.get/post/put/delete` が **classmethod 化**。MCPサーバは破壊的変更あり（Kenshoは未使用）。
- **0.4.12**: スパイダー向け `AutoThrottle`（サイト応答速度を測って遅延を自動調整、**block/rate-limit 時は遅延を倍化し `Retry-After` に従う**）、CSV/XML エクスポータ追加。

### 互換性の実物検証（信頼度: 高）
0.4.15 の wheel を scratch にダウンロードし中身を直接検査:
- `scrapling/__init__.py` に `_LAZY_IMPORTS` があり `from scrapling import Fetcher` は**維持**（Kensho の `sources/scrapling_fetch.py` の import は無改修で通る）。
