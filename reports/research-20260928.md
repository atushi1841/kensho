### 発見した情報（信頼度付き）

#### 1. Playwright v1.63.0 リリース（2026-09-04）【信頼度：高】  
情報源: https://playwright.dev/docs/release-notes / https://github.com/microsoft/playwright/releases/tag/v1.63.0
- **Test locks**: 共有リソース（外部サービス・グローバル設定）を使うテストに名前付き `lock` を宣言可能。同一lock名のテストはファイル・ワーカー・プロジェクト横断で並列実行されない
- **Selectorless `frameLocator()`**: `page.frameLocator()` / `frame.frameLocator()` がセレクタなしで呼べ、ページ内の任意のフレームを検索。iframe特定の手間が不要
- **`locator.visible()`**: `:visible` CSS疑似クラスの推奨代替。隠しテンプレート・オフキャンバス・重複ボタン等で役立つ
- **Step params / subtitles**: `test.step()` に `params` と `subtitle` 対応。トレースビューア・HTMLレポートで表示
- **ARIA & Screen snapshots in traces**: `tracing.start({snapshots:{dom:true,aria:true,screen:true}})` でアクションごとにAXツリーとスクリーンショットを同時記録。Display Ariaモードで並べて確認可能
- **New APIs**: `httpCredentials` が配列対応、`opfs` でOrigin Private File System永続化、`dialogclosed` イベント
- **Perfetto reporter**: Trace Event Format出力、`chrome://tracing` や Perfetto UI でワーカー別タイムライン表示
- **Browser versions**: Chromium 153.0.8010.12, Firefox 155.0, WebKit 26.6

#### 4. AIエージェント向けブラウザ自動化トレンド 2026【信頼度：中〜高】  
情報源: https://www.browserless.io/blog/state-of-ai-browser-automation-2026 / https://www.unbrowse.ai/blog/browser-automation-2026-complete-guide / https://browser-use.com/posts/bitter-lesson-browser-agents
- **三時代**: Script-Driven (〜2018) → API-Driven Playwright/Puppeteer (2018-2024) → **AI-Native (2024〜)**: Browser Use, Stagehand, Firecrawl, Unbrowse
- **Unbrowseの衝撃**: ブラウザを自動化せず、**内部APIエンドポイントを発見・キャッシュ・直接叩く**（中央値67ms vs Playwright 7.3s = **100倍高速**）。MCPサーバーとしても動作
- **ハイブリッド実践パターン**: (1) Unbrowseでデータ取得→キャッシュヒットなら即返却 (2) ミスならPlaywrightで操作→セッション受け渡しで次回からキャッシュ化 (3) 記事系はFirecrawl (4) 未知サイト探索はBrowser Use
- **Browser Useの「苦い教訓」**: モデルがコーディング上達するにつれ、**予め定義されたアクション列挙から「生CDPへの直接アクセス」へ移行**。`browser_exec` 1ツールに12ツールを統合、トークン60-66%削減。Playwrightのロケータ前提（closed shadow root見えない等）をCDPが回避
- **MCP標準化**: Playwright自体がMCPサーバー同梱（`npx playwright mcp`）、Chromex/Veil/CloakBrowserもMCPサーバー同梱。エージェントは標準ツール呼び出しでブラウザ操作可能
