```

Mozilla Firefox 151.0

# 全垢のUA vs 実バイナリ:
atushi16:     rv:150.0.1 Firefox/150.0.1  ← ±1 許容範囲
kudou:        rv:150.0.1 Firefox/150.0.1  ← ±1

TankanNotes:  rv:153.0  Firefox/153.0     ← ±2（やや古い）
zin20120731:  rv:150.0  Firefox/150.0     ← ±1
inobase1-4:   rv:152.0  Firefox/152.0     ← ±1
royalkensho:  rv:133.0  Firefox/133.0     ← ❌ 18バージョン乖離
```

**修正方法:** browser.py L234の `user_agent` を `rv:151.0` / `Firefox/151.0` に変更（実バイナリに合わせる）。

### 提案46【中】royalkensho UA rv:133.0 → 実バイナリ151.0に修正

**問題:** 新規7垢目royalkenshoのUAが実Firefoxバイナリ（151.0）と18バージョン乖離（rv:133.0）。他の全垢は150.0-153.0（±1）に収まっているが、royalkenshoのみ逸脱。

**危険度: 中** — 新規垢のfingerprint品質。実バイナリとUA不一致はJS検出リスク（x-bot-detection skill Pitfall明記）。履歴が浅い今が修正の最適タイミング。

**修正:**
`kensho/application/browser.py` L234:
```python
# 修正前
"user_agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:133.0) Gecko/20100101 Firefox/133.0",
# 修正後
"user_agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:151.0) Gecko/20100101 Firefox/151.0",
```

**期待効果:** 実バイナリとUAの一貫性確保 → royalkenshoのBOT判定リスク低減。
