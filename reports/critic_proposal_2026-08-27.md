### 提案44【中】proxy_watchdog の subprocess デコードエラー修正（2026-08-27新規発見）

**問題:** proxy_watchdog.py の `subprocess.run(..., capture_output=True, text=True)` が、日本語Windowsのコンソール出力（cp932/Shift-JIS）をUTF-8としてデコードしようとして `UnicodeDecodeError` を発生させ、**プロキシ再起動が失敗**する。

**証拠（今日3回発生・12:45-12:58）:**
```
Proxy TankanNotes:1085 is dead
Failed to restart proxy for TankanNotes: 'utf-8' codec can't decode byte 0x83 in position 17: invalid start byte
```
- 0x83 = cp932の2バイト文字の先行バイト（日本語メッセージ）
- 該当箇所: `kensho/utils/proxy_watchdog.py` L114 / L129 / L220 / L250 / L265 / L271 / L323 の計7箇所（`text=True`）
- **影響:** 再起動失敗で復旧が遅延（1085はegress経路で~13:00に復旧したが、コード起因の失敗が3回）。他の垢でもプロキシ死→再起動時に同様に発生し得る

**提案内容:**
1. 全 `subprocess.run(..., text=True)` 呼び出しに `errors="replace"` を追加（`text=True, errors="replace"`）
2. 解析対象（`status`="Up"/IP/件数）はすべてASCIIのため、置換（U+FFFD）による挙動変化なし
3. 既存テスト `test_proxy_watchdog.py` はそのまま通る見込み（引数追加のみ）

**危険度: 中**（自動復旧の信頼性。凍結リスク・BOTシグナルには直結しないが、プロキシ死→復旧遅延→応募機会損失が続く）

**期待効果:** プロキシ再起動が確実に成功し、自動復旧の遅延が解消される
