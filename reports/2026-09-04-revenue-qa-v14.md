## 重要な発見（申し送り）

1. **pricingInfos 階層が深い**: 前回QA v13 では `datasetItemCostUsd` / `eventPriceUsd` を直下で参照していたが、正しくは `pricingPerEvent.actorChargeEvents.{event-name}.eventPriceUsd` の2階層下。t_056b04f9 初回試行で `None` 判定したのはこの階層ミス（私の初版シェルスクリプトでも同じ失敗 → 修正版で5/5 PASS確認）
2. **act ID は username ではなくハッシュ**: `/v2/acts/{username}` は 404。`/v2/acts` リストで `id` フィールド（例: `mQaZFo6up4YZKepC3`）を使う必要あり
3. **前回QA v13 の `datasetItemCostUsd` 参照パスは誤り**: 9/4 05:15 の `pricingInfos=[PAY_PER_EVENT, actStart=$5e-05, dataset-item=$0.002]` は実は前回の collector 出力 / 内部表記を人間が読み替えたものと思われ、生 API の真の階層は今回確認した通り `pricingPerEvent.actorChargeEvents.*`
4. **scrapling未インストール問題継続**: 前回から継続中、`scripts/apify_seo_apply.py` 等が依存する可能性
