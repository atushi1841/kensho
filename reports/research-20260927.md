# 調査レポート（2026-09-27 / 収益化アイデア調査）

## 発見した情報（信頼度付き）

### 1. Webスクレイピング市場の成長と収益モデル（高信頼度）
- **情報源**: https://www.proxies.sx/blog/web-scraping-passive-income-developer-guide (2026/02/08)
- **内容**: Webスクレイピング市場は2025年$2.1B → 2030年$5.8B（CAGR 18.6%）。主要ドライバーはAI学習データ需要、ECインテリジェンス、AIエージェントインフラ
- **4つの収益モデル**:
  1. **Per-Request API** ($500-5,000/月) - 最もスケーラブル、RapidAPI/Apifyで配布
  2. **Recurring Dataset Sales** ($1,000-10,000/月) - 週次/月次データセットをサブスク販売
  3. **Apify Store Actors** ($5,000-20,000/月 TOP) - 80%収益配分、インフラ不要
  4. **Custom Scraping Consulting** ($50-200/時) - 最速収益だが時間売り

### 2. 日本オルタナティブデータ市場の急成長（高信頼度）
- **情報源**: https://newscast.jp/news/1106871 (IMARC Groupレポート 2026)
- **内容**: 日本市場2025年$7.1億 → 2034年$95.5億（CAGR 33.46%）。主な成長要因：データ主導投資戦略の採用、ウェブスクレイピングデータ・位置情報・衛星画像など多様なソース、規制明確化
- **重要**: 日本の機関投資家は米国/英国より導入遅れ → **「導入ギャップ」がビジネスチャンス**

### 4. x402プロトコルとAIエージェント決済の台頭（高信頼度）
- **情報源**: https://blog.cloudnative.co.jp/articles/cloudflare-monetization-gateway-x402-stablecoin-agent-payment/ (2026/07/02)

- **意義**: AIエージェントがAPI/データを自律購入する時代の「配管」が整備されつつある

## 次のテーマへの申し送り

### 未解決の疑問・深掘りすべき点

1. **「売る」チャネルの実証実験**: Apify Storeへのテスト公開1本目で、実際の需要・収益・サポート負荷を測定すべき。まずは無料Actorでダウンロード数・星評価を確認→有料化

2. **日本版MRRScoutの差別化**: MRRScoutは英語圏中心。**日本語情報源(note/Qiita/Zenn/日本語PHクローン/日本スタートアップDB)を独自収集**し、「日本市場適合度スコア」を付与するのが差別化の核

3. **データセット販売の初回顧客獲得**: Datarade出品 or Gumroad/note販売でテスト販売し、購入者フィードバックで商品化レベルを確認

4. **x402実装の技術検証**: Cloudflare Workers無料枠でx402ゲートウェイを構築し、既存API 1つを課金対象にしてテスト決済フロー確認

5. **競合調査の深掘り**: 日本国内の「スクレイピングデータ販売」「キャンペーン分析ツール」で既存プレイヤーの価格・機能・集客手法を詳細調査
