# 懸賞1,842件の自動応募ログを全部集計したら、「応募導線」と「当選枠」に地味な崖があった（2026W43）

国内懸賞 **1,842件**を自動収集し、9アカウントで **1,896件**のエントリーを実行した。その生ログから、応募導線・当選枠・締切の分布を機械可読な形で集計したのがこのレポートだ。手作業では絶対に作れない「1,842件横断の傾向」を見ていく。

## 何を測ったのか

- 対象: `data/collected_today.json` ほかスナップショット（1,842件）

- 実行: 自動応募 1,896件（アカウントあたり案件カバー率 11.4%）

- 判明した当選枠合計 120,154口 / 推定賞品価値 1,751,743円



## わかったこと(1): 伸びているキーワード

最も多く出現したのは `Amazon`（163件）、`#プレゼント企画`（123件）、`ギフト`（98件）、`サイン`（70件）、`ギフトカード`（67件）、`QUO`（66件）、`#モニター募集`（58件）、`周年`（57件）。単なる出現数ではなく、「そのキーワードの案件にどれだけ自動応募が刺さったか（応募率リフト）」も併記している。リフトが正のキーワードは、運用側の判断と需要が噛み合っている語だ。



## わかったこと(2): 当選枠の構造

枠数構成比は 2〜5名 551件、6〜20名 425件、枠数不明・記載なし 313件 の順。枠が大きい案件ほど当選確率は上がるが、実際に当選が積み上がっている枠レンジは実測当選テーブルを見ればわかる。



## わかったこと(3): 参加導線という見えない壁

応募導線は X 83.1%、未判定 15.1%、要確認 0.7%。X内で完結する案件は自動化できるが、LINE・外部フォーム・会員IDは1件ごとに人手または専用実装が必要で、ここが実質的な参入障壁になる。



## 再現方法

```bash
python3 scripts/kensho_data_journalism.py --week 2026W43
```

統計JSONは `reports/journalism/2026W43.json` に出力される。同じ入力からは同じ数値が出る（乱数も時刻依存の集計も使っていない）。

## まとめ

自動化の勝率を上げるのに効くのは、根性ではなく「構造の可視化」だった。
どの導線が自動化できて、どの枠レンジに当選が積み上がり、どのキーワードの案件に応募が回っていないか——
それらを毎週機械的に出しておくと、改善の順番が迷わなくなる。

対象データ: 1,842件 / 応募 1,896件 / 統計ハッシュ `186cf99533bea737`（qiita 用下書き・自動生成）
